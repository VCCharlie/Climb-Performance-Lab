## 2024-05-18 - Missing keyboard accessibility and aria labels on icon buttons in ActivityTable
**Learning:** Found several icon-only buttons in `ActivityTable.jsx` (Eye, Route, Edit, Trash) that lacked `aria-label`s, rendering them inaccessible to screen readers. Also, these action buttons were wrapped in a `div` hidden behind an `opacity-0 group-hover:opacity-100` pattern without including `focus-visible:opacity-100`, making them invisible during keyboard navigation. Additionally, the buttons missed proper visual focus rings (`focus-visible:ring-2 focus-visible:ring-yellow-400 focus:outline-none rounded-sm`).
**Action:** Added `aria-label` to the buttons and updated the wrapping container to include `focus-within:opacity-100` (so it appears when navigating via keyboard). Also added focus classes to the buttons and the adjacent anchor links (Intervals, Strava).
